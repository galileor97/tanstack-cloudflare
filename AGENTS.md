# Project

Full-stack boilerplate: TanStack Start (React 19, Router, Query) on Cloudflare Workers, with D1 + Drizzle, Better Auth (email/password + Google), shadcn/ui (Radix) and Tailwind CSS v4. Package manager: pnpm.

# Commands
- Dev server: `pnpm dev` (port 3000)
- Build: `pnpm build`
- Typecheck: `pnpm typecheck`
- Lint + format check: `pnpm check` (auto-fix: `pnpm exec biome check --write`)
- Test: `pnpm test` / single file: `pnpm exec vitest run <file>`
- DB: `pnpm db:generate` (migration from schema) → `pnpm db:migrate` (local D1) / `pnpm db:migrate:remote`
  - Bindings in `wrangler.jsonc` with `"remote": true` make `pnpm dev` use the real Cloudflare resources; check before migrating or writing data
- Env types: `pnpm cf-typegen` after changing `wrangler.jsonc` or `.dev.vars.example`
- Add UI component: `pnpm dlx shadcn@latest add <component>`

Before finishing a change, run `pnpm typecheck`, `pnpm check` and `pnpm build`.

# Architecture
```
src/
  routes/              # file-based routes: URLs, loaders, head(), guards only
  features/<name>/
    components/        # UI for this feature
    server/            # server-only modules (Worker env, D1, secrets, SDK clients)
    functions.ts       # server functions (createServerFn) callable from client code
    client.ts          # browser-side clients (e.g. authClient)
    schema.ts          # Drizzle tables for this feature
  components/          # shared components; components/ui = shadcn (generated)
  db/                  # D1 client (index.ts) + schema.ts re-exporting feature schemas
  lib/                 # shared utils: site.ts (SEO config), seo.ts, utils.ts (cn)
```

Rules (the import rules are enforced by Biome in `biome.json`):
- Routes stay thin: move UI into `features/<name>/components/` and data access into `server/` + `functions.ts`.
- Client code (routes, components, `client.ts`) must not import `cloudflare:workers`, `@/db` or anything in `features/*/server/`. Call a server function from `functions.ts` instead.
- No barrel `index.ts` files or `export *`. Import modules by direct path, e.g. `@/features/auth/components/sign-in-form`. Barrels pull whole features into the main bundle.
- Features don't import each other's internals; move shared code to `src/lib/` or `src/components/`.
- New tables: define them in `features/<name>/schema.ts`, re-export from `src/db/schema.ts` with a relative path (drizzle-kit doesn't resolve `@/`), then `pnpm db:generate`.
- Access Worker bindings/secrets via `import { env } from "cloudflare:workers"` (server-only).

# Auth
- Better Auth config: `src/features/auth/server/auth.ts`, mounted at `src/routes/api/auth/$.ts`.
- Read the session with `getSession()` from `@/features/auth/functions` (it strips the session token; never send the token to the client).
- Protected pages go under `src/routes/_authed/` (redirects to `/sign-in`, `noindex`).
- Browser actions (sign in/up/out, social) use `authClient` from `@/features/auth/client`.
- After adding Better Auth plugins that need tables, update `src/features/auth/schema.ts` (Better Auth CLI: `pnpm dlx auth@latest generate`).

# SEO
- Site-wide settings in `src/lib/site.ts` (name, production `url`, description, OG image).
- Every page route sets `head: () => seo({ title, description })`; use `noindex: true` for private pages.
- Canonical URL, `og:url`, JSON-LD and icons are added by `src/routes/__root.tsx`; don't add them per route.
- `/sitemap.xml` is generated from the router. Opt a route out with `staticData: { sitemap: false }`; add dynamic URLs in `getDynamicEntries()` in `src/routes/sitemap[.]xml.ts`.

# Code Style
- Biome: tab indentation, double quotes, organized imports; `@/` alias for `src/`
- Strict TypeScript, no unused locals/parameters
- camelCase for variables/functions, PascalCase for components, kebab-case file names
- Validate input with Zod (search params, forms, server function inputs)
- Styling: Tailwind CSS with `cn()` for class merging; prefer shadcn components over custom primitives

# Don't edit
- `src/routeTree.gen.ts` (generated by the router plugin)
- `worker-configuration.d.ts` (run `pnpm cf-typegen`)
- `src/components/ui/*` by hand unless needed; they're shadcn-generated and can be overwritten
- Existing migrations in `drizzle/`; generate new ones instead

# Secrets
- Local: `.dev.vars` (gitignored), template in `.dev.vars.example`
- Production: `wrangler secret put <NAME>`
